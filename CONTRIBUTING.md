# Участие в проекте

Для ошибки укажите версию приложения, версию Windows, выбранный источник данных и шаги воспроизведения. Журнал можно открыть на вкладке «Журнал». Не прикладывайте токены или данные авторизации.

Перед pull request запустите Ruff и тесты по командам из README. Изменения интерфейса должны работать на русском и английском. Настройки существующих пользователей нужно переносить через `migrate_stored`, сохраняя значения, которые не относятся к изменению.

Сборка Windows описана в [docs/BUILDING.md](docs/BUILDING.md).
